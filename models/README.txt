Put 3D models here (.glb .gltf .obj .iqm .vox .m3d) and press F6 in the game.
File name decides what the model replaces:
  car*.glb     - all cars (several files = random variety)
  player*.glb  - your character
  npc*.glb     - pedestrians
Size is fitted automatically. If a model faces the wrong way press F8 (rotates 90 degrees).

Animated characters: player.glb / npc.glb hold baked animation frames (many copies of the body in different poses).
The matching player.anim / npc.anim list the clips (name, first frame, frame count) - keep them next to the .glb.
  player: idle run sprint air aim aimrun airaim   npc: idle walk run dead
A model without a .anim file is shown as one static pose.
